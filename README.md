# opencode-termux

OpenCode AI assistant compiled for Android Termux (aarch64).

## Install

```bash
npm install -g opencode-termux
```

## Usage

```bash
opencode
```

## Update

```bash
opencode --update
# or
npm update -g opencode-termux
```

## Requirements

- Android with Termux
- aarch64 (ARM64) architecture
- Internet connection (for installation)
